Using the designer

The three panels

PanelWhat it does
Toolbox (left)Click a type, then the form, to place it. Below it, Controls on form lists every control with its control group and type: click one to select it (handy for controls that are hidden or hard to hit).
Design surface (middle)The form drawn by the real controls, pixel-exact, scaled by the zoom. Place, select, drag, resize here. A thin yellow frame is the form's edge.
Property panel (right)The selected control's properties, or the form's when nothing is selected. Changes apply live. The panel scrolls with the wheel when a control has many rows.

+ - 0 FZoom in, out, 1:1, fit. Ctrl/Cmd + wheel zooms around the mouse. The zoom box and the Fit and 1:1 buttons are above the surface.
Ctrl/Cmd + O, S, XOpen, Save, Export (always asks for the output folder).

Text fields in the panel

Every field is a real editor: arrows, Home/End, Shift to select, Alt/Ctrl + arrows by word, Cmd + Left/Right to the line ends, Ctrl/Cmd + A / C / X / V, undo and redo (Ctrl/Cmd + Z, Shift + Z or Ctrl + Y), double-click selects a word and triple-click everything. The designer is US-ASCII only: any character outside the printable ASCII range is dropped when typed or pasted.

Strict values: red and refuse

A value the real control would not accept (24:00 in a time box, 2026-02-30, a maximum below the minimum, a name that is a C++ keyword ...) is refused: the old value stays, the field turns red and the reason is shown under the rows and in the status line. Nothing invalid reaches the generated code.

Fonts, colours and layout

  • Font and colour rows open a dialog (the font dialog previews the control itself in that font and colours; a font's size is part of the font).
  • Border style (Standard / 3D / Sleek), Border size, Padding and Align are overrides: the field shows the control's default until you change it; clearing the field or choosing the default again removes the override. Alignment exists for labels and push buttons.
  • Fit (on the Width row of text-like controls) sets the exact width that shows the whole text.
  • Controls with a frame of their own caption (everything except Label, Push button, Check box and Radio button) get a label group: label text, position (Above / Below), alignment, font and colour.

Files

The form is saved as a readable JSON file (see The form file). Open starts in the folder it was last looking at (an application setting kept per user, not per form). Save starts on the form's own file. The folder the code was last exported to is remembered inside the form file (outputPath); if it no longer exists, the folder of the FormDesigner program is used. In scripts you can skip the dialogs: FD_FORM=form.json FD_OPEN=1 FD_EXPORT=1 build/FormDesigner exports from the command line.
