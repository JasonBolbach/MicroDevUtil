Generated code and your file

Export writes two files next to each other.

FileWho owns itWhat is in it
Form1.designer.hThe designer. Regenerated on every export: never edit it.Class Form1Base: every control as a public member, the SuperForm, constants, InitializeComponent(), Show(), Service(), and one empty virtual handler per event.
Form1.hYou. Written once, never changed again.Class Form1 : Form1Base with a constructor for your start-up code and an override stub per handler.

Using it in a sketch

#include "Form1.h"
Form1 ui(&lcd, &Enc, &BtnA, &BtnB);   // display, encoder, two buttons

void setup() { /* init lcd, Enc, BtnA, BtnB */ ui.Show(); }
void loop()  { ui.Service(); }              // focus, editing, touch, handlers

Handlers

ControlHandlers
Push buttonokBtn_Click()
Check box, radio buttonwifi_Change()
Spin box, slider, input / time / date box, color pickername_Change() (live, while editing) and name_Accept() (the user confirmed)
List box, combo box, tab barname_Change() (cursor moved) and name_Accept() (item chosen)
Menumenu1_Choose(uint16_t id) with one case per command, plus menu1_Change()
User drawscope_Draw(spr, body), and with Touch input scope_Pointer(e) and scope_Accept()
Gauge, graph, text box, label, progress barnone (display only). Update them from your code: load.SetValue(v), trace.AddSample(v).

To react to an event, write the override in Form1.h:

protected:
  void okBtn_Click() override { if (msgYesNo_Ask() == MSG_YESNO_YES) Save(); }
  void volume_Change() override { SetVolume(volume.GetLiveValue()); }

When you add controls later

The designer never edits Form1.h. Instead the status line (and FD_EXPORT=1) lists the handlers your file does not mention yet, for example add to it: cancelBtn_Click +1 more. Copy the stub you want from the protected: list of Form1.designer.h. Delete Form1.h to get a fresh one (it will not remember your code!).

Constants you get

  • MNU_... for every menu command, GRP_... for every control group, MSG_... for named message box buttons, and MSG_CANCELLED / MSG_PENDING. Use them instead of numbers.
TipThe constructor takes both buttons: Form1(dst, enc, btnA, btnB). Older exports took only one; re-export and pass &BtnB too.
Watch outDo not put your code in Form1.designer.h. The next export replaces the whole file and your changes are gone. Everything of yours goes in Form1.h.
