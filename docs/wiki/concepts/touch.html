Touch

Touch is optional. Give the form a SuperTouch wrapped around lcd.getTouch() and call form.Service(); every control then understands fingers.

SuperTouch touch(readFn); touch.ClickD_MAX = 0;
form.SetTouch(&touch);

The model

Finger down (PRESS): highlight the slot under it→Drag: change / move→Lift: accept
GestureIdle controlControl being edited
TapFocus it and start editing (one tap)Same as A short; tap outside = cancel
Long press-Same as A long (accept)
Drag up/down-Encoder steps, SuperControl::TouchDragStepPx pixels per step (default 4)

Which controls react how

  • StartOnPress controls start editing on touch-down: input box family, time/date box, spin box, list box, combo box (press opens it), menu, slider, colour picker bands.
  • IdleTapActs controls act on the first tap: tab bar and menu. Instant controls (check box, radio button, push button) simply act on a tap.
  • Precise picking: list, combo, menu, tabs, message box, slider and colour picker map the finger position directly to the item or value.

Under the hood

SuperForm::PumpTouch() converts SuperTouchEvents into SuperPointerEvents (PRESS, DRAG_START, DRAG_MOVE, DRAG_END, TAP, LONG_PRESS) and routes them to the edited control or the form's active one. Controls override OnPointer(); most call SuperPointerDefault(IO, *this, e, stepPx).

Desktop mouse coordinates

Never map SDL mouse coordinates by hand: the window is resizable and hi-dpi. Use LovyanGFX's own SDL touch emulation through lcd.getTouch().

Drag anchors

A DRAG_START event can already carry a moved position (moves are merged). Anchor drags at StartX/StartY.
