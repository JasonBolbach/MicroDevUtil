SuperForm: focus and screens

SuperForm form(&Enc, &BtnA);
form.Add(&spin); form.Add(&slider); form.Add(&bar, false);   // false = shown, never focused
form.SetOnEdit(onEdit, nullptr);
form.Draw();
void loop() { form.Service(); }

What it does

  • The encoder moves the focus box (DrawPreview(true) on the focused control, dimmed DrawPreview(false) on the rest).
  • Button A short starts the focused control's edit; Service() runs it without blocking.
  • Polls the touch panel and routes touch.
  • Calls Tick() on controls (animation), and batches DMA pushes during Draw().

Pages

For tabbed screens: put each page's controls in a list, hide the old page with SetVisible(false, false), show the new one the same way, then call form.Draw() once. Hidden controls are erased with ColHighlightClear (your screen background) and free their sprite.

Drawing order and focus order

SettingEffect
ctl.SetZOrder(n)Drawing order for overlapping controls. The lowest number is in front (drawn last). Equal numbers are drawn in the order they were added. Touch hits the front-most control first.
ctl.SetTabOrder(n)Focus order. The encoder visits the lowest number first and wraps round. Equal numbers are visited in the order they were added. Until you call form.SetFocus() (or touch a control) the first control in this order holds the focus.

Both default to 0, which is simply the order of form.Add(). They are plain numbers on the control, so gaps are fine (10, 20, 30 lets you slot one in later).

c.SetTabOrder(0); a.SetTabOrder(1); b.SetTabOrder(2);   // wheel goes C, A, B
back.SetZOrder(1); front.SetZOrder(0);                    // 'front' is drawn over 'back'
Overlap and redrawsOrder is applied when the form draws everything (Draw(), Redraw()). A single focus change or animation tick redraws just that control, so on overlapping controls call form.Draw() after such changes if the stacking must stay exact.

Popups

When a popup (combo list, message box) closes, call form.Redraw(x, y, w, h, bg) to repaint the covered rectangle.

Set the backdrop colour

Hidden controls and focus boxes are erased with ColHighlightClear or a theme Backdrop. If your screen is not black, set it or you will leave black holes.
