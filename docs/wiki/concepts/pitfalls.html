Pitfalls and fixes

SymptomCause / fix
Ghost pixels, label area not transparentpushSprite key must be lgfx::rgb565_t(KeyColor); a plain int is read as RGB888. KeyColor = 0x0001, so avoid that colour in your own drawing.
Sprite buffer maths gives garbage16-bit LGFX buffers are byte-swapped RGB565; readRect into a sprite needs (lgfx::swap565_t*).
Combo / message box restore is garbageMost SPI panels cannot readRect. Use SetBackdrop(&sprite), a sprite destination, or SetRestore(fn).
Wheel events missing (desktop)Panel_sdl swallows them; the library uses SDL_AddEventWatch.
Huge value jumps while testingEncoder speed scaling on rapid ticks (spinner and slider keep it on purpose).
Hidden controls leave a coloured patchSet ColHighlightClear (or a theme Backdrop) to your screen background.
Blank control, red outlineOut of RAM. See Memory and performance.
S3: "PSRAM chip is not connected"The module's PSRAM is octal: board_build.psram_type = opi, memory_type = qio_opi. Forcing quad PSRAM kills it.
Phantom button B / random cancels on a touch boardA button or encoder pin collides with TOUCH_INT or another part. Check Pins.h; keep USE_ENCODER / USE_BUTTONS false until fitted.
Upload fails "Could not open /dev/cu.usbmodemXXXX"VS Code PlatformIO saved a per-project customPort. Reset the status-bar port selector to Auto.
Slow redraw on SPISharedBuffer + UseDMA + LabelOpaque; page changes with SetVisible(v,false) + one Draw().

Portability rules for the headers

  • Only LovyanGFX, SuperGUI and the C++ standard library. No SDL, no desktop code, no <chrono> or threads.
  • Use lgfx::millis() / lgfx::delay(), not Arduino-only calls, inside the controls.
