Writing your own control

Two options: use SuperUserDraw (no subclassing, you draw in a callback), or derive a real control.

  1. Derive from SuperControl (or SuperTextBox for text). Implement RenderBody(x,y,w,h), plus BodyHeight() if the body is not one font line.
  2. Editable? Own a SuperEditIO IO; override StartEdit / Service / IsEditing. Call IO.Flush() on start, IO.Changed() on a live change, IO.Accepted() after an accepted Finish(). Draw the cursor only while State == EDIT_ACTIVE.
  3. Touch: override OnPointer() and usually call SuperPointerDefault(IO, *this, e, stepPx); StartOnPress() / IdleTapActs() choose when it starts.
  4. Animated? Override Tick() and return true when a redraw is due.
  5. Name it Super<Thing>.h, add a README row, an examples/<Name>Example and a demo page.
  6. Compile for both micros, run a headless drive, look at the picture.
