Getting started

Every control needs three things: a LovyanGFX destination (a display or a sprite), a position and width, and, for the editable ones, a SuperEncoder and two SuperButtons.

#include <LovyanGFX.hpp>
#include "SuperSpinBox.h"

LGFX         lcd;                         // your LovyanGFX display class
SuperEncoder Enc(2, 3);                   // A / B pins
SuperButton  BtnA(4, true), BtnB(5, true);// active low

SuperSpinBox spin(&lcd, 10, 10, 120, &lgfx::fonts::Font2, &Enc, &BtnA, &BtnB);

void setup() {
  lcd.init(); lcd.fillScreen(TFT_BLACK);
  Enc.Begin(); BtnA.Begin(INPUT_PULLUP); BtnB.Begin(INPUT_PULLUP);
  spin.SetRange(0, 100); spin.SetLabel("Volume"); spin.SetValue(50);
  spin.DrawPreview(true);                 // draw it (with the focus box)
}
void loop() { if (spin.BeginEdit()) { /* accepted: spin.GetValue() */ } }

Three ways to run a control

StyleHowUse when
Blockingif (c.BeginEdit()) ... returns when the user accepts or cancelsA single modal dialog, simple sketches
Non-blockingc.StartEdit() then call c.Service() from loop()Anything that must keep running (sensors, animation, networking)
FormSuperForm owns the focus and the edit of many controlsA real screen of controls. Recommended.

Most screens should use SuperForm. It also drives touch, animation timers (gauge glide, auto-redraw) and redraws.
