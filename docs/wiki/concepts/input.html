Input: encoder and buttons

InputAction
EncoderMove / change. SuperEncoder already scales speed (1 / 5 / 20); lists with 20 items or fewer step by sign only.
Button A shortSelect / next slot. Input box: edit the slot. Colour picker: next component. Menu / list / tabs: choose.
Button A longAccept.
Button B shortCancel. Menu: back one level.
Button B longRevert and keep editing. Menu: leave.
Medium click, double flagIgnored on purpose: a reset must feel intentional.

Desktop emulation

Mouse wheel = encoder, wheel click = Button A, right click = Button B (desktop_input.h). The left mouse button is the touch panel.

Where touch and keys meet

Touch events are converted into the same keys and encoder steps (they are injected into the control's SuperEditIO), so a user can start with the finger and finish with the encoder in the same edit.

PinsA phantom Button B or random cancels on a touch board usually means a button or encoder pin collides with another part's pin such as TOUCH_INT. Check Pins.h before choosing pins.
