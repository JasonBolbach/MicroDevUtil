SuperLabel

Just text. No border, no title and no padding by default, with left / centre / right alignment, vertical alignment, word wrap and live values.

Display onlysrc/SuperLabel.h

What it looks like

Real renders from the library (headless, dark theme, Font2, shown at 2x).

Quick start

SuperLabel title(&lcd, 0, 6, 240, &lgfx::fonts::Font4, "Settings", SuperControl::ALIGN_CENTER);
title.SetTextColor(TFT_CYAN);
SuperLabel help(&lcd, 10, 40, 220, &lgfx::fonts::Font2, "A long text that wraps onto several lines.");
help.SetWrap(true);
form.Add(&title, false); form.Add(&help, false);   // display only
value.SetTextf("%d.%d C", t / 10, t % 10);           // live value

Unique features

  • Alignment: SetAlign(ALIGN_LEFT / ALIGN_CENTER / ALIGN_RIGHT) for every line; SetVAlign(VALIGN_TOP / MIDDLE / BOTTOM) together with a fixed height from SetBodyHeight(h) (0 = as tall as the lines).
  • \n starts a new line; SetWrap(true) also breaks at spaces (a word wider than the control is broken inside). The height follows the number of lines.
  • Without wrapping a line that is too wide is cut and ends in "..." (SetEllipsis(false) just clips). SetMaxLines(n) limits the lines and puts "..." on the last one.
  • SetTextf(fmt, ...) is printf style and redraws only when the text really changed, so it is cheap to call every loop pass.
  • SetLineGap, SetUnderline, SetTextColor. It is still a SuperControl, so a border or label is available if you want one.

GUI workflow

Display only: nothing to operate, it never takes focus. Add it with form.Add(&label, false).

Event workflow

None. Change the text with SetText / SetTextf; the label redraws itself when the text changed.

Main API

CallWhat it does
SetText(s) / SetTextf(fmt,...)Text; redraws on change
SetAlign(a)Horizontal alignment
SetVAlign(v) + SetBodyHeight(h)Fixed height, vertical alignment
SetWrap(b)Word wrap
SetMaxLines(n)Limit lines
SetTextColor(c)Text colour (ColBg = background)
GetLineCount()Lines after wrapping

Tips and tricks

TipPut the title of a page in a large font centred label and a hint line under it in a small grey wrapped label.

Pitfalls

Watch outThe control fills its whole area with ColBg. Set it to the colour of what is behind (or use ApplyTheme); there is no transparent mode, so a label over a picture shows a coloured rectangle.
Watch outEvery label is a sprite: many tiny labels cost RAM, see memory. One multi-line label is cheaper than several single-line ones.
