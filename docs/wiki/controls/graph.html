SuperGraph

A display-only scrolling line graph.

Display onlysrc/SuperGraph.h

What it looks like

Real renders from the library (headless, dark theme, Font2, shown at 2x).

Quick start

SuperGraph g(&lcd, 10, 10, 200, &lgfx::fonts::Font2, 80 /*body height*/);
form.Add(&g, false);
g.AddSample(sensor());

Unique features

  • One sample per pixel of inner width by default (SetCapacity(n) changes that; the line is scaled).
  • Automatic vertical range (min..max of what is shown plus a margin) unless SetRange(lo,hi).
  • ShowRange prints top / bottom values; ShowGrid draws three faint lines.
  • Memory: capacity x 4 bytes plus the sprite.

GUI workflow

Nothing to operate.

Event workflow

None. AddSample(v, redraw=true) appends and redraws; pass false to batch.

Main API

CallWhat it does
AddSample(v, redraw)Append
SetRange / SetAutoRangeVertical scale
SetCapacity(n)Samples kept
Clear()Remove all

Tips and tricks

TipUse a fixed range for stable visuals; auto range rescales as extremes scroll out.
