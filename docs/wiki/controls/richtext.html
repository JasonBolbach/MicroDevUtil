SuperRichText

A scrollable, read-only text area that understands a few HTML-like tags: colours, background, underline, strike, big text, alignment, tab stops, rules. One font, no syntax checking.

Editable (modal edit)src/SuperRichText.h

What it looks like

Real renders from the library (headless, dark theme, Font2, shown at 2x).

Quick start

SuperRichText help(&lcd, 10, 10, 220, 200, &lgfx::fonts::Font2, &Enc, &BtnA, &BtnB);
help.SetTextStatic("<center><color=yellow><big>Help</big></color></center>\n"
                   "<hr>\n"
                   "Turn the <u>encoder</u> to scroll.<br>Press A to close.");
help.BeginEdit();                    // the user scrolls; A closes (accepted), B closes (cancelled)

Unique features

  • Tags: <br> <tab> <hr> <color=red>..</color> (#RGB, #RRGGBB or a name) <bg=#003366>..</bg> <font color=.. bg=..> <b> <i> <h1> (with style fonts) <u> <s> <big> (double size) <left> <center> <right>, and the entities &lt; &gt; &amp; &quot; &apos; &nbsp; &#65;.
  • Lenient on purpose: unknown tags (<p>, <img>, and <b> / <i> when no style font is registered) are ignored, a < that does not start a tag is shown as it is, an unclosed tag stays in effect to the end. Nothing is ever reported: bad text shows as bad text. A closing tag returns to the control's default (there is no nesting stack).
  • One font by default. Only what LovyanGFX does natively is supported: colours, filled backgrounds, lines (underline / strike / rule), text scaling and fonts you register. Style fonts: SetStyleFont(SuperRichText::FONT_BOLD, &lgfx::fonts::FreeSansBold9pt7b) (also FONT_ITALIC, FONT_BOLDITALIC, FONT_HEADING) makes <b> <i> <b><i> and <h1> use that font (<strong>, <em>, <h2>, <h3> are the same tags). Fonts of different sizes on one line share a baseline. A slot with no font leaves its tag ignored, and a line is as tall as its tallest font. Costs nothing unless you register a font (it is then linked into your program).
  • A plain new line in the text is a line break (like an editor), <br> too. Words wrap at the width, a word wider than the control is broken inside. Tab stops: SetTabChars(n).
  • Memory: SetTextStatic(const char*) does not copy: a string literal stays in flash. The layout is a table of 16 bytes per visual line (200 lines = 3 KB); the text is read again when drawn, never parsed into a tree. SetText(std::string) copies.
  • SetShowSource(true) draws the text with every tag visible: handy to debug your markup.
  • The same tags work in SuperLabel and SuperMessageBox after SetRich(true) (off by default: plain text stays plain).

GUI workflow

Encoder, A short/long, B short/long and touch as in Input. Like the list box it is edited by scrolling: the encoder scrolls a line, ButtonA (short or long) closes it (accepted), ButtonB short closes it (cancelled), ButtonB long jumps back to the top. Touch: drag to scroll. A thin bar at the right edge shows the position when the text is longer than the area. In code: ScrollTo, ScrollBy.

Event workflow

The edit contract: SetOnAccept when the user closes the text with ButtonA. Use it to leave the help screen.

Tips and tricks

TipAuthor the text in the Form Designer: the Rich text control has a source editor with a Rendered view (see Using the designer).
TipThe Form Designer's own ? help window is a SuperRichText: tools/FormDesigner/src/HelpDialog.h is a complete example.
TipUse <tab> for two-column lists (key, description): set the stop with SetTabChars.

Pitfalls

Watch outAlignment applies to a whole line and is taken where the line's first text starts: <center>Title</center> centres that line, text <center>more does not.
Watch outThere is no HTML whitespace collapsing: spaces and new lines are kept as written.
Watch outA text longer than the area needs the encoder (or touch) to scroll: add the control to a form so it can take focus, or scroll it with ScrollBy.
