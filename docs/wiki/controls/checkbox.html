SuperCheckBox

A check box with a caption. Instant: a click toggles it; there is no edit state.

Instant (acts on click)src/SuperCheckBox.h

What it looks like

Real renders from the library (headless, dark theme, Font2, shown at 2x).

Quick start

SuperCheckBox cb(&lcd, 10, 10, 160, &lgfx::fonts::Font2, "Enable sound");
cb.SetOnAccept([](void*){ sound = cb.GetChecked(); });

Unique features

  • A square glyph about one font tall, caption on its right; a caption that does not fit is clipped.
  • SetCaption is separate from SetLabel (a label above / below).
  • Toggle() flips and fires callbacks; SetChecked() changes silently (no callbacks).

GUI workflow

Focus it with the encoder and press A short, or tap it: it flips at once. There is no cursor because nothing stays "being edited".

Event workflow

Both OnChange and OnAccept fire on a change, OnChange first. In a form it reports EDIT_ACCEPTED on the next Service().

Main API

CallWhat it does
SetChecked(b)Silent
GetChecked()State
Toggle()With callbacks
SetCaption(s)Caption text

Tips and tricks

TipUse SetChecked to initialise from saved settings without triggering your handler.

Pitfalls

Watch outSetChecked never calls your callbacks; update dependent UI yourself.
