SuperGUI controls wiki

Encoder + two buttons + touch UI controls for ESP32 and RP2040, drawn with LovyanGFX sprites.

This wiki explains each control (what is special about it, how the user works it, which events it fires, tips and pitfalls) and the concepts they share. For the complete reference tables and RAM numbers see README_Controls.md; for a step-by-step tutorial see GettingStarted_Controls.md; for runnable sketches see examples/.

Using this wiki

It is plain static HTML: open docs/wiki/index.html in a browser, no server needed. The pages are generated by docs/wiki/_src/build.py from the two content files next to it; edit those and rerun the script rather than editing the HTML.
